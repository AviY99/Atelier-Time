Atelier Time — Privacy Policy

Effective date: October 30, 2026 · App developer: Avi Yosfan

At a glance

Atelier Time is an offline class-management timer for live-model drawing and sculpting workshops. It does not require an account and does not automatically upload your saved classes, sound choices, or Run reports to the developer.

1. Information used by the app

The app processes the information you enter or select to operate its timers, including class names, class schedules, posing sessions, breaks, end-time choices, saved classes, and sound preferences.

When you run a class, the app can automatically create diagnostic Run reports in private storage on your device. These reports contain timing information, events and user actions, class rules and names, sound-selection metadata, and basic device context: Android API version, device manufacturer and model, app version and timezone. The diagnostic reports do not include the contents of your selected audio files or their document URIs.

2. Where information is stored

Saved classes, sound settings, references to user-selected sound files and diagnostic Run reports are stored locally in the app's private Android storage. The reviewed app does not have account registration, cloud synchronization, advertising or analytics upload. Android app backup is disabled in the reviewed version.

3. Sharing and exporting

The app does not automatically transmit the locally stored information above to the developer. If you choose to export a Run report, you select its destination using Android's system document picker. That destination may be a local folder or a separate app or cloud provider you have selected. Once exported, the file is subject to your chosen destination's privacy practices and is outside the app's private storage. You control whether to export it and where it goes.

4. Permissions, notifications and sound files

Atelier Time can request Android notification permission to display the active class status. If you decline, class timing and sound cues can still function, although the status notification may be unavailable. During an active class, the app uses an Android foreground service to support ongoing status display, notification cleanup and background continuity. Android system controls can still interrupt app execution.

When you select a personal sound file, the app uses Android's document picker and accesses only the specific file you choose. It does not request general access to your personal files. The optional keep-screen-awake setting applies when the app is visible.

5. Retention and deletion

Locally stored information remains available across normal app updates until you remove it through the relevant in-app controls or uninstall the app. Saved classes and diagnostic reports have in-app deletion controls. Removing the app normally removes its private stored information; files that you previously exported to other destinations must be deleted separately from those destinations.

6. Security

The app relies on Android's private application storage and Android's system document picker for user-selected file access. No internet account, password or developer-operated server is required to run the reviewed app. As with any software, no system or device is guaranteed to be free of security risks.

7. Children and other users

The app is designed as a class-management tool. It does not request age, name, email address or account registration. Workshop organizers should avoid putting personal or sensitive information about participants into class names or exported Run reports.

8. Changes

This policy may be updated if the app's functionality or data practices change. The effective date at the top of this page will be revised when substantive updates are published.

9. Privacy contact

For privacy questions or requests about Atelier Time, contact the developer, Avi Yosfan, through Instagram Direct Message (@aviyosfan) or submit an inquiry in the Atelier Time GitHub issue tracker. These contact methods are hosted by third-party platforms and may require their own accounts; please do not post sensitive personal information publicly in GitHub issues.
